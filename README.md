# QSE Ecosystem
March and lewis and scupitfy ltd

QSE Core powers:
- Sculptify Ltd
- March and Lewis
- AI coach
- wallet/payments
- training
- streaming
- rewards
- memberships
- marketplace connectors

## Run (local)
```bash
npm install
npm run dev
```

## Run (Docker)
```bash
docker compose up --build
```

## Open
- http://localhost:5000
- http://localhost:5000/sculptify
- http://localhost:5000/march-lewis
